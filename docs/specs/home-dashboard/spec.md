# 가족 전체 준비 현황과 아직 못 본 소식

## 필수 참고 자료

- [제품 방향](../../../PRODUCT.md): 가족 전체가 같은 준비 정보와 의견을 확인한다.
- [승인된 시안](prototype.html): 홈 본문의 정보 순서, 여행 소개, 체크 집계와 새 소식 탐색. 시안의 예시 데이터와 검토 도구는 제품 기능이 아니다.
- [준비 체크리스트](../preparation-checklists/spec.md): 준비 항목, 공동·가족·개별 완료 상태와 의견.
- [공통 헤더](../../decisions/app-header.md), [공통 하단 메뉴](../../decisions/app-navigation.md), [디자인 안내](../../../DESIGN.md): 최신 공통 화면 기준. 시안 검토 이후 확정된 상단의 유일한 h1·중복 제목 제거와 5개 하단 탭 기준이 우선한다.

## 사용자에게 제공할 결과와 승인 범위

홈에서 공동 → 가족 → 개별 순서로 가족 전체의 준비 상태를 확인한다. 각 집계는 기존 체크리스트의 완료 체크를 세며, 가족·개별 항목별 완료 수도 펼쳐 본다. 로그인한 사람이 아직 보지 않은 방명록 글과 준비 의견을 모아 보여준다. 소식에서 해당 본문으로 이동해 읽고 홈에 돌아오면 미확인 목록에서 빠진다.

사용자가 이 방향과 시안을 승인하고 나머지 세부 구성을 위임한 뒤, 준비하기 구현과 충돌 없이 실제 구현 및 push를 요청했다.

## 관찰 가능한 수용 기준

1. 공동은 항목 수, 가족은 항목 수 × 가족 수, 개별은 항목 수 × 구성원 수로 집계한다. 저장되지 않았거나 false인 체크는 미완료다. 준비하기의 저장 상태를 재사용하며 별도의 완료 상태를 만들지 않는다.
2. 공동·가족·개별 카드가 이 순서로 나타나며 각각 완료/전체와 진행 막대를 표시한다. 가족·개별은 펼치면 항목별 완료 가족 수·인원 수를 볼 수 있다.
3. 본인이 작성한 내용은 새 소식에서 제외한다. 다른 구성원이 작성한 방명록 글과 준비 의견 중 본인이 읽지 않은 내용만 최신순으로 표시한다.
4. 전체·방명록·준비 의견으로 필터링하며 각각의 미확인 수를 표시한다. 소식이 없으면 모두 확인했다는 안내를 표시한다.
5. 방명록 소식은 해당 글 위치로 이동한다. 준비 의견 소식은 해당 주제 영역을 펼치고 본문 위치로 이동한다. 접힌 의견은 단순 준비하기 방문만으로 읽음 처리하지 않는다.
6. 본문이 실제 보이는 경우에만 구성원별 읽음 기록을 저장한다. 다른 구성원의 기록에는 영향을 주지 않으며 새로고침·재로그인 이후에도 유지된다. 기록 저장 실패는 알리고 재시도할 수 있다.
7. 기존 준비하기의 체크 변경 권한·가족 공유·의견 작성은 유지된다. 읽음 저장은 로그인한 구성원을 서버에서 확인한다.
8. 출발일까지의 D-day를 한국 날짜 기준으로 표시하고 열린 화면에서도 갱신한다. 여행 날짜는 2027-05-13~16이다.
9. 좁은 화면에서 가로 넘침 없이 사용하고 본문 스크롤 전후 하단 메뉴가 유지된다. 로딩·조회 오류는 기존 공통 상태 표현을 사용한다.

## 확정된 제약과 근거

- 전체 현황 중심, 체크 수 집계, 공동 → 가족 → 개별 순서는 사용자 지정이다.
- 새 소식은 로그인한 사람이 아직 보지 않았는지로 판단한다. 시간 구간이나 모든 가족이 공유하는 하나의 확인 상태를 사용하지 않는다.
- 상단은 최신 공통 헤더 계약을 따르고 본문에는 중복된 홈 제목을 추가하지 않는다.

## 변경 가능한 가정

- 본문이 화면에 유의미하게 표시되면 읽음으로 간주한다. 홈의 한 줄 미리보기는 읽음이 아니다.
- 본인이 작성한 글·의견은 이미 본 것으로 취급한다.
- 소식은 재방문·새로고침 시 조회한다. 푸시·실시간 구독은 추가하지 않는다.
- 필터는 기존 RadioGroup을 사용한다. 시안의 알약 모양은 구현을 고정하지 않는다.
- 하단 탭 자체의 새 소식 점 표시는 추가하지 않는다. 미확인 정보는 홈에서 제공한다.
- 가족·개별 체크 수를 공동 항목과 합친 단일 전체 퍼센트는 제공하지 않는다.

## 범위 밖

방명록 댓글 알림, 푸시·이메일·운영체제 알림, 준비 권한 변경, 새로운 준비 항목, 여행 스케쥴·여행 정보 본문의 신규 기능은 포함하지 않는다.

## 미뤄 둔 결정과 남은 위험

별도 미결정 없음. 화면에 표시된 내용을 읽음으로 간주하는 기본값이 실제 독서 완료를 보장하지는 않는다. 다른 가족의 새 글을 열린 홈에 자동 전달하는 실시간 갱신은 포함하지 않는다.
