# 항공권 리서치 결과 카드

## 사용자에게 보이는 결과

가족이 여행 정보에서 2026년 11월 22일 항공권 조사 요약을 읽고, 같은 화면에서 전체 보고서를 열어 비교와 예약 방법을 확인한다.

## 승인된 범위

- 사용자가 검토한 [시안](prototype.html)을 기준으로 여행 정보 맨 위에 새 카드를 추가한다.
- 제목은 ‘2026년 11월 22일 기준 항공권 최저가 리서치 결과’로 표시한다.
- 2027년 5월 13~16일, 가족 10명, 대한항공 운항 조건을 표시한다.
- 최저 조회 합계 7,267,800원과 인천 06:55 출국·18:15 또는 19:45 귀국을 요약한다.
- 가족 일정 추천인 김포 09:15 출국·19:35 귀국, 조회 합계 7,380,100원, 가족 전체 차액 112,300원을 함께 표시한다.
- 성인 운임 7명·소아 3명을 두 묶음으로 조회한 합계이며 10석 확약·최종 결제가는 아니라는 설명을 요약에도 표시한다.
- ‘자세히 보기’는 앱 안의 화면 높이를 사용하는 보고서 창을 연다. 기존 HTML 문서 전체와 그 안의 목차·필터·계산·문의 문안 복사 기능을 유지한다.
- 닫기 버튼 또는 Escape로 보고서를 닫으면 원래 카드 위치와 버튼 초점으로 돌아온다.
- 기존 여행 정보의 발행·읽음 규칙을 적용하여 홈 새 소식에서도 해당 카드로 이동할 수 있다.

## 관찰 가능한 수용 기준

- 여행 정보에서 이 카드가 기존 랜드마크 카드보다 먼저 보인다.
- 날짜·금액·인원·편명 및 시간은 승인된 보고서와 일치한다.
- 자세히 보기에서 보고서의 여섯 본문 섹션과 다섯 항공편 조합을 모두 읽을 수 있다.
- 보고서 내부 목차 이동과 공항 필터가 동작하고, 보고서를 닫아도 여행 정보의 스크롤 위치가 유지된다.
- 휴대폰과 큰 화면에서 요약과 닫기 동작이 잘리지 않는다.
- 홈의 새 소식에서 카드로 이동하는 기존 동작이 유지된다.

## 제약과 근거

- 조사일은 고정한다. 나중에 열어도 새로운 실시간 조회 결과처럼 날짜를 바꾸지 않는다.
- 보고서는 기존에 작성한 HTML 원문을 보존한다. 승인된 시안은 참고 자료이며 운영 UI로 복사하지 않는다.
- 카드와 보고서 창에는 기존 디자인 구성 요소를 사용한다.

## 변경 가능한 기본 가정

- 보고서 창의 큰 화면 최대 너비는 기존 앱 본문 너비에 맞춘다.
- 보고서를 새로 열 때는 원문 처음부터 표시한다.
- 외부 예약 링크는 원문과 같이 새 탭에서 열린다.

## 범위 밖과 남은 위험

- 새 항공권 검색, 예약·결제, 가격 알림, 가격 자동 갱신은 하지 않는다.
- 실제 좌석 재고와 최종 결제가는 이 기능으로 확정되지 않는다.
- 보고서의 외부 링크 가격과 예약 조건은 이후 달라질 수 있다.
- 다른 탭의 화면 구조나 기존 여행 정보 내용은 변경하지 않는다.
