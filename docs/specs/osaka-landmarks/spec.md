# 오사카 랜드마크 사진 카드

## 사용자 결과와 승인 범위

가족이 여행 정보 탭에서 오사카의 대표 장소를 실제 사진과 짧은 이야기로 알아보고, 방문 참고 정보와 위치를 확인한다. 사용자가 승인한 [사진 카드 시안](prototype.html)을 기준으로 한다.

- 오사카성·도톤보리·쓰텐카쿠·우메다 스카이빌딩·가이유칸의 카드 다섯 개를 추가한다.
- 이번에 추가한 랜드마크 카드들을 기존 도시 이름 이야기와 간소한 날씨 카드보다 위에 표시한다.
- 각 카드에 장소명, 일본어 표기, 지역, 한 줄 설명, 대표 사진 한 장, 짧은 소개와 ‘작은 발견’을 표시한다.
- 대표 사진은 높이 약 144px의 가로형으로 표시하고 사진 출처를 연결한다.
- ‘방문 전에 알아두기’를 펼쳐 방문 참고 정보를 읽고, 다시 접을 수 있다.
- 펼친 내용에서 지도 링크를 새 창으로 열 수 있다. 각 카드의 공식 관광 정보 링크도 새 창으로 열린다.

## 수용 기준

- 여행 정보의 표시 순서는 오사카성 → 도톤보리 → 쓰텐카쿠 → 우메다 스카이빌딩 → 가이유칸 → 도시 이름 이야기 → 현재 날씨다.
- 다섯 카드 모두 승인한 시안과 같은 실제 장소 사진을 표시하고 사진 출처가 함께 보인다.
- 처음에는 각 카드의 방문 참고 정보가 접혀 있다. 카드별로 독립적으로 펼치고 접는다.
- 지도 링크가 해당 장소를 가리키고 공식 관광 정보 및 사진 출처 링크가 제공된다.
- 모바일과 넓은 화면에서 본문·사진·링크에 가로 넘침이 없고 하단 메뉴는 본문 스크롤과 독립적으로 고정된다.
- 기존 도시 이름 이야기의 펼치기와 날씨 조회·새로고침이 계속 동작한다.

## 제약과 근거

- 사용자는 다섯 장소의 카드와 실제 사진을 넣은 수정 시안을 승인했다.
- 기존 공통 헤더·하단 메뉴, semantic token, shadcn 구성 체계를 유지한다.
- 장소 소개의 출처는 오사카관광국이며 사진 출처와 원본 주소를 함께 보존한다.
- 이미지가 늦게 표시되어도 사진 영역의 높이는 유지한다.

## 덮어쓸 수 있는 기본 가정

- 다섯 장소는 하나의 추가 묶음으로 취급하고 승인한 시안의 장소 순서를 유지한다.
- 콘텐츠는 개발자가 관리하는 정적 정보다. 실제 운영시간·요금·예약 정보를 별도로 복제하지 않고 공식 관광 정보 링크를 제공한다.
- 시안의 시스템 글꼴 대신 앱에 이미 적용된 글꼴을 유지한다.

## 범위 밖과 유보

- 장소 검색·필터, 즐겨찾기, 일정 편집·추가, DB 저장 및 콘텐츠 관리 화면은 포함하지 않는다.
- 다른 탭의 동작과 정보 순서를 변경하지 않는다.

## 위험

- 외부 지도·관광 정보 사이트의 주소나 내용은 변경될 수 있다.
- 사진은 장소 소개 자료이며 방문 시기의 실제 풍경·계절을 보장하지 않는다.
