# 오사카 여행 정보 카드

## 사용자 결과와 승인 범위

가족이 여행 정보 탭에서 오사카에 관한 짧고 흥미로운 이야기를 읽고 현재 날씨를 간결하게 확인한다. 사용자가 승인한 [시안](prototype.html)을 기준으로 한다.

- 새로 추가된 정보를 위에 표시한다. 현재는 도시 이름 이야기 → 현재 날씨 순서다.
- 도시 이름 이야기에는 大와 阪의 뜻, ‘큰 언덕’이라는 한자 풀이, 우에마치 대지 북쪽에서 넓어진 지명 이야기를 담는다. 정확한 유래에 여러 설이 있음을 명시한다.
- 옛 표기 大坂과 현재 표기 大阪 이야기는 버튼으로 펼치고 다시 접는다.
- 각 이야기의 확인 가능한 출처를 새 창에서 열 수 있다.
- ‘알고 가면 더 재미있는 오사카’라는 별도 섹션 제목을 표시하지 않는다.
- 날씨는 작은 카드에 기온·날씨 상태·날씨 아이콘·일본 현지 기준 시각과 제공처만 표시한다. 수동 새로고침과 기존 15분 자동 갱신을 유지한다.

## 수용 기준

- 여행 정보 진입 시 도시 이름 카드가 날씨 카드보다 위에 있다. 이후 정보 추가 시에도 추가 순서의 역순으로 보여준다. 날씨 데이터 갱신은 카드 추가로 취급하지 않는다.
- 옛 표기 이야기의 펼치기·접기가 동작하며 출처 링크가 제공된다.
- 실제 날씨를 표시하고 체감온도·최고/최저·습도·바람·강수확률 상세 영역은 표시하지 않는다.
- 날씨의 로딩과 조회 실패 상태를 표시한다. 재조회 실패 시 기존 정보가 있으면 이전 정보임을 알리고, 새로고침 성공 시 오류가 사라진다.
- 좁은 모바일 화면에서도 카드와 본문에 가로 넘침이 없고 하단 메뉴가 본문 스크롤과 독립적으로 고정된다.

## 제약과 근거

- 사용자 확인: 날씨를 아주 간소하게 줄이고 가장 최근 추가한 이야기를 먼저 읽도록 한다.
- 기존 프로젝트의 색상 token과 shadcn 구성 요소, 공통 상단·하단 메뉴를 따른다.
- 어원의 확정되지 않은 설을 역사적 사실로 단정하지 않는다.

## 덮어쓸 수 있는 기본 가정

- 여행 정보는 개발자가 추가하는 정적 콘텐츠다. 새 카드는 추가 순서에 따라 기존 카드 위에 표시한다.
- 시안의 기본 글꼴은 시스템 글꼴이며 실제 앱의 기존 글꼴 설정을 유지한다.

## 범위 밖과 유보

- 콘텐츠 작성·편집 관리 화면, DB 저장, 검색·필터, 다른 오사카 이야기 카드는 이번 범위에 포함하지 않는다.
- 다른 탭과 가족 로그인·권한을 변경하지 않는다.

## 위험

- 날씨 제공처 장애 시 현재 날씨를 불러오지 못할 수 있다. 오류 안내와 재시도로 대응한다.
- 출처는 외부 일본어 자료이며 사이트 접근 가능 여부에 영향을 받는다.
