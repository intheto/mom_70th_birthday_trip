# 여행 준비 체크 리스트

## 사용자에게 제공할 결과

가족은 준비하기 탭에서 공동·가족·개별 준비를 구분해 점검하고 공동 항목에 의견을 남긴다. 완료 상태는 DB에 저장되어 다시 접속해도 유지되며, 이후 홈 화면에서 같은 상태를 집계할 수 있다.

이 문서는 화면 아이디에이션과 검토 결과다. 함께 저장한 시안은 임시 데이터와 브라우저 내 동작을 사용하며 실제 인증·DB 저장·가족 간 동기화는 구현하지 않았다.

## 승인된 범위와 화면 구성

페이지 제목은 `여행 준비하기`다. 제목 위의 별도 문구, 여행 날짜·기간 및 준비 현황 요약은 표시하지 않는다. 공동 → 가족 → 개별 체크 리스트 순으로 표시한다. 모든 항목에 체크박스가 있고, 제목에는 항목에 어울리는 이모지를 사용한다.

### 공동 체크 리스트

- ✈️ 항공편 예약
- 🏨 숙소 예약
- 🗓️ 일정 정하기
- 🎟️ 오사카 주유 패스 준비

각 항목은 가족 전체가 공유하는 완료 상태 하나를 가진다. 김영욱만 공동 항목의 완료 상태를 변경할 수 있으며 다른 모든 구성원은 저장된 상태를 확인할 수 있다. 권한 안내는 섹션에 한 번 제공한다.

각 항목 아래에서 기존 의견을 클릭 없이 바로 읽고 작성할 수 있다. 작성란과 `의견 남기기` 버튼은 한 줄에 배치하고, 여러 줄 입력 시 작성란이 늘어난다. 의견이 없어도 작성란을 바로 표시한다. 일정 정하기는 `📍 가고 싶은 장소`와 `🍽️ 먹고 싶은 음식`으로 나누고 각 구분에 의견을 독립적으로 작성·조회한다. 일정 전체의 완료 체크는 하나다. 모든 가족 구성원이 본인 이름으로 의견을 남기고 함께 읽는다.

### 가족 체크 리스트

- 💊 상비약 챙기기
- 💳 결제 수단 준비

가족 항목에는 의견 작성 영역이 없다. 각 항목은 어머니·아들래미 가족·딸래미 가족별로 서로 다른 완료 상태를 가진다. 같은 가족의 구성원은 동일한 가족 상태를 공유하며 누구나 자기 가족 항목을 체크·해제할 수 있다. 항목별 전체 집계 기준은 구성원 수가 아닌 3가족이다.

### 개별 체크 리스트

- 🛂 여권 만들기
- 📱 핸드폰 통신 준비

개별 항목은 구성원별 완료 상태를 가진다. 결제 수단 준비는 가족 체크 리스트에만 포함한다. 가족·개별 항목은 문구 길이에 맞는 작은 카드로 배치하고 공간이 부족하면 줄바꿈한다.

## 관찰 가능한 수용 기준

1. 세 섹션에 위 항목만 표시하고 모든 항목에 완료 체크박스가 있다.
2. 섹션과 카드의 좌우 기준선이 일치하고 좁은 화면에서도 가로 넘침 없이 읽고 조작할 수 있다. 본문을 스크롤해도 하단 메뉴는 앱 화면 하단에 유지된다.
3. 공동 항목에 김영욱이 저장한 완료 상태가 다른 구성원으로 접속해도 표시되고, 다른 구성원은 이를 변경할 수 없다.
4. 가족 항목은 한 가족의 상태가 다른 가족의 상태에 영향을 주지 않는다. 같은 가족으로 접속하면 같은 상태를 확인한다. 같은 가족의 모든 구성원이 자기 가족 항목을 체크·해제할 수 있으며 다른 가족의 상태를 변경할 수 없다.
5. 개별 항목은 구성원마다 독립적으로 상태를 저장하고 본인의 상태를 확인한다. 변경 권한은 아래 가정에 따른다.
6. 체크 상태는 새로고침·재접속 후에도 보존된다. 공동은 항목별 하나, 가족은 항목별 3가족, 개별은 항목별 구성원 수 기준으로 집계 가능한 상태를 제공한다.
7. 공동 의견은 항목에 귀속되며 일정의 장소·음식 의견도 서로 섞이지 않는다. 작성자 이름과 내용은 가족 모두가 재접속 후에도 확인할 수 있다.
8. 준비하기에는 완료 인원·전체 인원·현황 요약·완료 수 배지를 표시하지 않는다. 체크박스 자체의 완료 표현은 유지한다.
9. 저장·의견 등록 중에는 중복 조작을 막고, 실패하면 실패를 알리며 다시 시도할 수 있다. 로딩과 의견이 없는 상태도 같은 화면 문법을 유지한다.

## 제약과 이유

- 공동·가족·개별의 집계 단위를 구분한다. 가족 체크는 같은 가족 구성원이 여럿이어도 중복 집계하지 않는다.
- 준비하기는 체크와 의견에 집중하며 현황 수치는 추후 홈에서 제공한다.
- 전체 페이지의 제목·항목·보조 문구 위계, 체크박스 크기, 여백과 정렬을 통일한다. 기존 의견과 입력란은 항상 표시하되, 입력란은 기본 한 줄 높이로 공간을 줄인다. 이 동작은 시안의 접기·펼치기 방식보다 이후 사용자 요청을 우선한 것이다.
- 실제 구현은 공식 UI 컴포넌트와 프로젝트 토큰을 사용한다. HTML 시안의 직접 작성된 스타일·태그는 구현 구조를 지정하지 않는다.

## 변경 가능한 가정

- 개별 항목은 본인만 체크·해제한다. 보호자의 대리 체크는 승인되지 않았다.
- 완료 체크는 같은 변경 권한을 가진 사용자가 해제할 수 있다.
- 의견 수정·삭제는 이번 범위에 추가하지 않는다.
- 구체적인 글자 크기·이모지와 기본 여백은 시안을 출발점으로 실제 화면에서 조정할 수 있다.

## 미결정 사항과 남은 위험

- 홈 화면의 구체적인 집계 표현과 배치는 홈 화면을 설계할 때 다시 연다. 이번 범위는 집계할 수 있는 완료 상태를 보존하는 것까지다.
- 시안의 체크와 의견은 검토용 동작이므로 실제 권한·DB 동기화의 검증 증거로 사용할 수 없다.

## 범위 밖

홈 화면 변경, 추가 준비 항목, 입국·패스 구매 조건 안내, 일정 자동 생성, 알림은 포함하지 않는다. 이번 작업은 준비하기 화면과 체크·의견 요구사항에 한정한다.
