# 공통 상단 헤더

## Decisions

- 로그인 이후 공통 헤더의 왼쪽에는 현재 선택한 탭 이름을 한 줄로 표시한다. 홈·준비하기·여행 스케쥴·여행 정보·방명록에서 각각 해당 메뉴 이름을 사용한다.
- 별도의 축하 이모지나 작은 부제를 붙이지 않는다. 로그인한 구성원의 이름은 기존처럼 함께 표시한다.

## Why

사용자는 여행 스케쥴 시안을 검토하며 기존 상단 문구 대신 선택된 탭의 문구를 표시하도록 직접 요청했다. 모든 탭에서 현재 위치를 같은 방식으로 보여주기 위해 탭 이름과 상단 제목을 일치시킨다.

## Reconsider when

- 주요 메뉴 이름이나 상단에서 현재 위치를 안내하는 방식이 바뀔 때.

## Still-rejected alternatives

- 선택한 탭과 무관한 고정 브랜드 문구 — 사용자가 현재 탭 이름을 표시하도록 변경을 요청했다.
- 기존 축하 문구와 작은 여행 부제를 함께 쓰는 방식 — 사용자가 간소화를 요청한 구성이다.
