# 공통 상단 헤더

## Decisions

- 로그인 이후 홈·준비하기·여행 정보·방명록의 공통 헤더에는 `우리 가족 오사카 여행`을 한 줄로 표시한다.
- 브랜드 문구에 별도의 축하 이모지나 작은 부제를 붙이지 않는다. 로그인한 구성원의 이름은 기존처럼 함께 표시한다.

## Why

사용자는 기존의 축하 문구와 부제가 웹앱의 컨셉과 이질적으로 느껴진다고 판단했다. 가족이 함께 오사카 여행을 준비하는 의미를 간결하게 표현하기 위해 `우리 가족 오사카 여행`을 직접 선택했고, 모든 탭에서 같은 문구를 쓰도록 확정했다.

## Reconsider when

- 앱의 여행 대상이나 목적지가 바뀌어 공통 브랜드 문구를 다시 정해야 할 때.

## Still-rejected alternatives

- 탭마다 다른 브랜드 문구를 쓰는 방식 — 같은 앱 안에서 화면 간 정체성이 달라진다.
- 기존 축하 문구와 작은 여행 부제를 함께 쓰는 방식 — 사용자가 간소화를 요청한 구성이다.
