# 공통 하단 메뉴

## Decisions

- 로그인 이후 주요 메뉴는 `홈 → 준비하기 → 여행 스케쥴 → 여행 정보 → 방명록` 순서로 앱 화면 하단에 고정한다. 본문을 위아래로 스크롤해도 메뉴의 위치는 변하지 않는다.
- 여행 스케쥴은 준비하기와 여행 정보 사이에 두고, 일정임을 알아볼 수 있는 달력 아이콘을 사용한다.
- 스크롤은 본문 영역에서 이루어진다. 휴대폰 모형으로 검토할 때도 메뉴는 브라우저 창이 아니라 모형 안의 앱 화면 하단에 붙는다.

## Why

사용자는 스크롤 위치와 관계없이 주요 메뉴를 사용할 수 있도록 요청했다. 모든 탭에서 같은 이동 방식을 유지하고, 긴 방명록과 댓글을 읽은 뒤에도 바로 다른 탭으로 이동할 수 있게 한다.
