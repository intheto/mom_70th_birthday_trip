# 여행 정보 카드

## Decisions

- 여행 정보 탭은 정보를 카드로 모으고, 나중에 추가된 카드가 먼저 보이게 한다. 날씨 데이터가 갱신되어도 추가 순서는 바뀌지 않는다.
- 현재 날씨는 기온·상태·아이콘·기준 시각·제공처와 새로고침을 담은 작은 카드로 표시한다.
- 도시 이름 이야기는 날씨보다 나중에 추가된 정보이므로 위에 표시한다. 별도의 ‘알고 가면 더 재미있는 오사카’ 섹션 제목을 두지 않는다.

## Why

홈의 새 소식에는 로그인한 구성원이 아직 확인하지 않은 여행 정보 카드를 표시한다. 랜드마크는 장소별 카드 단위로 읽음을 구분한다. 새 소식의 시점은 카드의 발행 시점이며, 날씨 수치 갱신으로 이미 읽은 날씨 카드를 다시 새 소식으로 만들지 않는다. 이는 미확인 정보를 알려주되 반복되는 날씨 갱신으로 새 소식이 쌓이지 않도록 하기 위한 기준이다.

사용자는 이야기 카드를 검토한 뒤 새로 추가되는 정보를 먼저 읽고 날씨는 간소하게 확인하도록 순서와 정보량을 직접 변경했고, 수정된 시안을 승인했다.

## Boundaries

- 정렬은 여행 정보 카드의 추가 순서에 적용하며 다른 탭의 정렬을 규정하지 않는다.

## Reconsider when

- 사용자가 특정 카드를 고정하거나 직접 순서를 바꿀 필요가 생길 때.
